# استراتيجية الذكاء الاصطناعي ومحفظة حالات الاستخدام

AI Strategy and Use-Case Portfolio

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-EXE-201 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يبني المشاركون استراتيجية للذكاء الاصطناعي ومحفظة لحالات الاستخدام لجهة افتراضية، انطلاقًا من سجلات اصطناعية للاستراتيجية والعمليات والبيانات المالية. فيقيّمون نضجها، ويفرزون حالات الاستخدام بحسب الغموض والمخاطر، ويبنون نموذجين أوليين لحالتين مرشحتين على نماذج مستضافة لاختبار جدواهما، ويختارون بين البناء أو الشراء أو الشراكة، ويتتبعون القيمة المتوقعة حتى الحسابات المالية. والمشروع الختامي محفظة ودراستا جدوى يدافع عنهما المشارك أمام لجنة استثمار تجريبية.

**الصيغة:** دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-exe-201/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يحلل نضج الجهة في الذكاء الاصطناعي من حيث الاستراتيجية والحوكمة والبيانات والبنية التحتية والأفراد والتطبيقات والأثر، استنادًا إلى ملاحظات مقابلات اصطناعية وقوائم أنظمة وموازنات | Applied | ملف تقييم فيه دليل لكل درجة، وأهم ثلاث فجوات تحدّ من المحفظة |
| LO2 | يصنف حالات الاستخدام بحسب الغموض والمخاطر، ويسند إلى كل منها نمطًا: الأتمتة، أو الإدارة بضوابط حماية، أو إتاحة الاستكشاف، أو إبقاء القيادة للإنسان، على مجموعة من 25 حالة استخدام مرشحة | Applied | مصفوفة فرز فيها مبرر لكل تصنيف، ومالك مسمّى لكل حالة عالية المخاطر |
| LO3 | يختبر ادعاءات الجدوى ببناء نموذجين أوليين لحالتي استخدام على نموذج مستضاف، وتشغيل كل منهما على عشر حالات واقعية، استنادًا إلى حالتي استخدام مفروزتين ووثائق اصطناعية | Applied | مذكرة جدوى لكل حالة فيها نسبة النجاح وأنواع الإخفاق وقرار بالمضي أو إعادة العمل أو التوقف |
| LO4 | يقارن بين خيارات البناء والشراء والشراكة من حيث ملاءمة القدرات والتكلفة الإجمالية للملكية والتحكم في البيانات والارتهان للمورِّد والوقت اللازم لتحقيق القيمة، استنادًا إلى ثلاث أوراق خيارات بأسعار تقديرية | Applied | مصفوفة خيارات مقيَّمة، والشرط الذي يتوقف عليه الاختيار |
| LO5 | يبني محفظة مرتبة بحسب الآفاق الزمنية، فيها بوابات تمويل، وقيمة متتبَّعة حتى بنود قائمة الدخل، استنادًا إلى نتائج الفرز وملف النضج وضمن موازنة ثابتة | Performance | محفظة ودراستا جدوى فيهما خط الأساس والتكاليف والمخاطر ومعيار التوقف، يُناقَشان أمام لجنة |
